# Line Height and Vertical Alignment

Inline content sits on a **line box**. When you mix text with other inline elements (like a small icon box), they may not line up the way you'd expect.

Edit `style.css` so the icon and the text in the toolbar are **vertically centered** relative to each other within the bar.

## Self Check

- The colored icon box and "Dashboard" text appear vertically centered with each other.
- The toolbar has a consistent height.
- You used `line-height`, `vertical-align`, or both — not flexbox, grid, floats, or absolute positioning.
