# Display Types

For this exercise, you'll practice the difference between block and inline display. The page shows a simple profile with label/value pairs. Right now every `<span>` is forced to `display: block`, so each piece of text stacks on its own line.

Edit `style.css` so that:

- Each label and its value appear **on the same line**
- Each pair appears on **its own row**
- Do **not** use flexbox, grid, or floats

## Self Check

- "Name:" and "Jane Doe" share one line; "Email:" and "jane@example.com" share the next, and so on.
- You changed `display` on the spans (not the row containers).
- The layout works without flexbox, grid, or floats.
