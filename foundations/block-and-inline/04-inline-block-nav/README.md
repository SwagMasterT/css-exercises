# Inline-Block Navigation

This exercise uses `display: inline-block` to lay out a horizontal navigation bar without flexbox or floats.

The list items are block-level by default, so the links stack vertically. Edit `style.css` so the nav items sit in a **single horizontal row** with visible, padded link areas.

## Self Check

- All four nav links appear on one horizontal row.
- Each link has padding and a background color (the starter CSS provides these — you shouldn't need to change them).
- You used `display: inline-block` (or similar inline-level display) on the list items.
- You did not use flexbox, grid, or floats.
