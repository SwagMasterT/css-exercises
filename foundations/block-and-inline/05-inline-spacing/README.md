# Inline Spacing

Inline elements behave differently from block elements when it comes to spacing. **Vertical margins don't affect inline elements**, but horizontal margins and padding do.

The tag pills below are inline, but the starter CSS tries to use vertical margin for spacing — which won't work. Edit `style.css` so the tags have comfortable vertical size and even horizontal spacing between them.

## Self Check

- All tags sit on a single horizontal row (they may wrap on narrow screens — that's fine).
- Each tag has visible vertical padding so it looks like a pill, not a flat strip of text.
- Tags have horizontal spacing between them (margin or padding — your choice).
- You did not use flexbox, grid, or floats.
